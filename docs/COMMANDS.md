# 命令与自然语言

## 身份

```text
/视觉状态
/爱弥斯外貌
/视觉校准
```

## 生图

```text
/看看你
/自拍
/生活状态
/现在在干嘛
/今天穿什么
爱弥斯，今天让我看看你
爱弥斯，去海边拍一张
爱弥斯，你长什么样
```

`你现在在干嘛`、`今天穿的什么` 只读取生活状态回答，不生成图片。

生图会读取 `private_companion` 当前的活动、地点、穿搭、情绪、天气和睡眠状态。

## 造型

```text
/添加造型 白色连衣裙     （带服装图）
/换装 白色连衣裙
/造型列表
/恢复默认
```

## 图片比对

```text
/图片比对               （带图）
这张图是不是我           （带图）
这个发饰和我的一样吗      （带图）
```

## 成本

```text
/视觉成本
```

## 备份

```text
/视觉备份
/视觉恢复 /path/to/visual_backup_xxx.zip
```
