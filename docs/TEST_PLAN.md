# 测试计划（A–J）

目标：不做无意义的 100 轮手工聊天，用最小验收覆盖文档 A–J。

## A. 外貌记忆

- 连续问 3 次：发色、发型、刘海、发饰、瞳色
- 检查 `identity_block` 注入后回答一致

## B. 长期记忆

- 重启一次 AstrBot
- 检查 `/视觉状态` 的素材数和身份版本保留
- 不跑 100 轮聊天，持久化由 SQLite 保证

## C. 图片识别

- 一张爱弥斯官方图
- 一张相似角色图
- 分别 `/图片比对`
- 检查是否给出具体差异，而不是只回答“像/不像”

## D. 自定义造型

```text
带图 /添加造型 测试裙
/换装 测试裙
/造型列表
/恢复默认
```

## E. 恢复默认

- 切换自定义造型后 `/恢复默认`
- 检查当前造型回到官方默认
- 检查官方身份字段没有被造型覆盖

## F. 自主生图

```text
爱弥斯，今天让我看看你
```

检查：

- 是否触发
- 是否调用规划器
- 是否调用 gpt-image-2
- 是否发回 QQ 图片

## G. 角色一致性

- 生成 3 张不同场景
- 检查发色、双马尾、刘海、发饰、瞳色
- 记录哪些字段漂移

## H. 换装生图

```text
/换装 测试裙
爱弥斯，今天让我看看你
```

检查服装变化，同时固定特征保持。

## I. 缓存与速度

- 同一请求连续两次
- 第二次应命中缓存，不再调用生图 API
- `/视觉成本` 不应增加

## J. 异常

- gpt-image 502
- MiMo 超时
- 图片损坏
- API Key 错误
- 检查是否回复明确错误，不影响普通聊天
